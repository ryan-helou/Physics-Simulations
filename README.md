# Physics Simulations

**A desktop program that shows classic physics experiments as moving, interactive animations.**

The centrepiece is a double pendulum: one pendulum hanging from the end of another. It is a famously chaotic system, meaning a tiny change in how it starts leads to a completely different swing. The program draws the path the bottom weight traces as it swings, so you can watch those wild patterns build up. The app also includes a Newton's cradle and a particle-attraction screen.

## What you can do with it

- Start, stop, and reset a swinging double pendulum.
- Change the length and weight of each arm and the strength of gravity with sliders, and see how the motion changes.
- Turn the traced path on or off.
- Look at the early Newton's cradle and particle-attraction screens.

I built the double pendulum; Anish Mehra built the Newton's cradle, with help from classmates on the particle-attraction screen and the main menu.
